# うちの子アーカイブ

このリポジトリには、現在のサイトを構成する静的なHTML・CSS・JavaScript・データJSON・画像・音声を収録しています。

## ローカルで見る

リポジトリのファイルをダウンロードし、`index.html` をブラウザで開いてください。ブラウザの制限で一部のデータが読み込めない場合は、リポジトリのフォルダで簡易HTTPサーバーを起動して開いてください。

## 編集

- ページ: `*.html`
- 見た目: `*.css`
- 動き: `*.js`
- 作品・キャラクター・ギャラリー等のデータ: `data-*.json`
- 画像・音声: `assets/`

GitHub Pagesは設定していません。このリポジトリは非公開管理用です。
